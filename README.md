# Skills das aulas — Empreende.IA

Skills entregues nas aulas da Empreende.IA.

**Como instalar:** baixe o zip da skill na pasta `zips/` (ou o anexo da aula), abra o Claude, anexe o zip
e peça: "Instale esta skill na pasta de skills pessoais do Claude Code deste computador, substituindo se já existir."
Depois feche e abra o Claude de novo para a skill aparecer no `/`.
