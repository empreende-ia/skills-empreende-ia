# Direções visuais por arquétipo de negócio

De onde saem as propostas da **Rodada 1**. Não é um cardápio pra escolher e servir: é o ponto de
partida que você **filtra pelo "o que a marca NÃO é"** da Rodada 0.

**Como usar:** ache o arquétipo → leia a direção esperada → monte a **A (esperada)** com ela → monte a
**B (contraste)** invertendo uma das quatro variáveis abaixo → monte a **C** a partir da referência que
a pessoa mandou.

---

## As 4 variáveis que definem uma direção

| Variável | Extremos | O que comunica |
|---|---|---|
| **Temperatura** | fria (azul/verde/cinza-azulado) ↔ quente (âmbar/terracota/cinza-quente) | fria = técnica, precisa, distante · quente = humana, próxima, artesanal |
| **Face** | grotesca neutra ↔ serifada editorial ↔ mono técnica ↔ display expressiva | é o sotaque da marca; muda mais a percepção que a cor |
| **Papel da cor** | funcional (só CTA e foco) ↔ estrutural (blocos inteiros pintados) | funcional = sóbria, confiável · estrutural = enérgica, jovem |
| **Densidade** | densa (informação junta) ↔ arejada (muito vazio) | densa = ferramenta, produtiva, barata · arejada = premium, calma, cara |

Inverta **uma** delas pra ter a proposta B. Inverter todas as quatro não gera contraste, gera outra
marca — e a pessoa não consegue comparar.

## Catálogo de arquétipos

### 1. Produto técnico / SaaS / ferramenta de dev

| | |
|---|---|
| **Temperatura** | Fria. Escuro por padrão — é onde o público já vive (editor, terminal). |
| **Face** | Grotesca com boa altura-x + **mono de verdade** (não decorativa) em código, label e número. |
| **Papel da cor** | Funcional e escassa. Cor = ação ou estado. Nunca decorativa. |
| **Densidade** | Média a densa. Público técnico lê informação junta sem reclamar; espaço demais parece landing de curso. |
| **Raio / elevação** | Raio pequeno (8–12px). Borda no lugar de sombra. Elevação por superfície mais clara. |
| **Assinaturas que funcionam** | Cursor piscando · prompt `$` ou `→` no wordmark · bloco de código com resultado real · número monoespaçado. |
| **Evite** | Verde-ácido sobre preto (clichê #2) · gradiente roxo-azul (clichê #3) · ilustração isométrica de servidor. |
| **Cor de assinatura** | `#3B82F6` azul elétrico · `#22D3EE` ciano · `#F97316` laranja (contraste bom com escuro) · `#A78BFA` lilás — **só** se o resto for rigorosamente neutro. |

### 2. Consultoria / serviço profissional B2B

| | |
|---|---|
| **Temperatura** | Fria ou neutra. Escuro sóbrio ou claro quase branco — as duas leem "sério". |
| **Face** | Grotesca de boa família com **tracking negativo forte** no display. Serifada só se a marca vende tradição. |
| **Papel da cor** | Muito funcional. A autoridade vem do **espaço e do tipo**, não da cor. |
| **Densidade** | Arejada. Respiro é o que precifica. Seção com 96px de padding vertical. |
| **Raio / elevação** | Raio médio, sombra mínima ou glow. Nada de card flutuando. |
| **Assinaturas** | Número de prova em destaque (21M+, 12 anos) · pull-quote em itálico com borda lateral · overline em caixa-alta com tracking largo. |
| **Evite** | Foto de banco de imagem com aperto de mão · azul-corporativo `#0055A4` · tudo centralizado. |
| **Cor de assinatura** | `#10B981` esmeralda · `#0EA5E9` azul-céu · `#B45309` âmbar queimado · `#334155` grafite com um acento mínimo. |

### 3. Saúde / clínica / bem-estar

| | |
|---|---|
| **Temperatura** | Quente-neutra. Claro sempre — escuro em saúde lê como clínica de emergência. |
| **Face** | Humanista com terminações suaves. Nada geométrico frio, nada condensado. |
| **Papel da cor** | Estrutural leve: blocos grandes em tom pastel da assinatura, texto em cor cheia. |
| **Densidade** | Arejada. Ansiedade se combate com espaço. |
| **Raio / elevação** | Raio generoso (16–24px). Sombra suave e difusa. Nenhum canto reto. |
| **Assinaturas** | Ilustração de linha simples no lugar de foto de estoque · cartão de horário/agendamento como componente-assinatura · ícone dentro de círculo pastel. |
| **Evite** | Azul-hospital `#0077C8` com cruz · verde-farmácia saturado · pessoa sorrindo de jaleco em foto genérica. |
| **Cor de assinatura** | `#0D9488` teal · `#7C3AED` violeta suave (bem-estar, terapia) · `#E11D48` rosa-carmim (feminina, dermato) · `#65A30D` verde-oliva (natural, nutrição). |

### 4. Varejo / e-commerce / DTC

| | |
|---|---|
| **Temperatura** | Depende do produto — mas comprometa-se. Meio-termo mata conversão de marca. |
| **Face** | Display forte na capa + texto neutro e legível no resto. O produto é a estrela; o tipo não disputa. |
| **Papel da cor** | Estrutural na marca, **funcional no fluxo de compra**. O botão de comprar é a única cor da página de produto. |
| **Densidade** | Densa na grade, arejada na página de produto. |
| **Raio / elevação** | Raio pequeno ou zero em foto de produto (deixa a foto ser o retângulo), médio em botão. |
| **Assinaturas** | Tratamento de preço (peso, alinhamento, moeda menor) · badge de estado (últimas peças, novo) · a foto sangrando até a borda. |
| **Evite** | Vermelho de promoção `#FF0000` · contador regressivo pulsando · 8 cores no menu de categorias. |
| **Cor de assinatura** | `#1E1B4B` índigo profundo (premium) · `#B45309` caramelo · `#DC2626` vermelho **só** se for a marca, não a promoção · preto absoluto + uma cor de destaque. |

### 5. Dados / fintech / financeiro

| | |
|---|---|
| **Temperatura** | Fria. Claro para leitura de relatório, escuro para painel operacional — escolha pelo uso real. |
| **Face** | Grotesca com **numerais tabulares** (`font-variant-numeric: tabular-nums`). Número que dança de largura destrói tabela. |
| **Papel da cor** | Rigorosamente funcional + **semântica travada**: subiu/desceu, positivo/negativo. Assinatura fora dessa dupla. |
| **Densidade** | Densa. Quem lê número quer número por tela. |
| **Raio / elevação** | Raio pequeno. Borda fina. Zebra sutil em tabela. Sombra quase nenhuma. |
| **Assinaturas** | Sparkline inline ao lado do número · variação com seta e cor semântica · tabela com cabeçalho fixo. |
| **Evite** | Verde/vermelho como cores da marca (colidem com a semântica) · gradiente em gráfico de barra · dourado de "riqueza". |
| **Cor de assinatura** | `#1D4ED8` azul confiança · `#0F766E` teal escuro · `#4338CA` índigo · **evite verde e vermelho na marca** — reserve pra alta e baixa. |

### 6. Criativo / estúdio / agência / artista

| | |
|---|---|
| **Temperatura** | Extrema, num sentido ou noutro. Neutro aqui é o mesmo que invisível. |
| **Face** | Display expressiva com personalidade + texto neutro segurando. É onde vale gastar em fonte paga. |
| **Papel da cor** | Estrutural e ousado: seções inteiras pintadas, inversão de tema entre blocos. |
| **Densidade** | Assimétrica de propósito. Grade quebrada é a assinatura. |
| **Raio / elevação** | Costuma ser 0 — corte reto, cara editorial. Ou totalmente arredondado. Nunca o meio. |
| **Assinaturas** | Tipo gigante sangrando fora da tela · cursor customizado · seção que inverte pra tema oposto · scroll horizontal no portfólio. |
| **Evite** | Ser criativo só no hero e genérico no resto · animação que atrapalha ler · roxo-azul de novo. |
| **Cor de assinatura** | Qualquer coisa cheia de convicção: `#FF3B00` laranja-sinal · `#CCFF00` lima **(só sobre claro)** · `#111111` + uma cor única · duotone. |

### 7. Educação / curso / infoproduto / mentoria

| | |
|---|---|
| **Temperatura** | Quente-neutra. Escuro funciona bem se o público for técnico; claro, se for iniciante. |
| **Face** | Grotesca amigável e muito legível — o público vai ler texto longo. Display com peso alto pra ancorar promessa. |
| **Papel da cor** | Funcional, com um uso estrutural reservado: progresso, módulo concluído, aula atual. |
| **Densidade** | Arejada no marketing, densa na área do aluno. São dois modos do mesmo sistema — declare os dois. |
| **Raio / elevação** | Médio (12–16px). Cards são o componente central: aula, módulo, depoimento. |
| **Assinaturas** | Barra/anel de progresso na cor da marca · número do módulo com tratamento tipográfico · card de aula com estado (bloqueado/atual/concluído). |
| **Evite** | Amarelo de "atenção, oferta" · seta vermelha desenhada em cima do print · emoji como marcador de módulo · numeração 01/02/03 decorativa onde não há sequência. |
| **Cor de assinatura** | `#10B981` esmeralda · `#F59E0B` âmbar (energia, sem virar promoção) · `#4F46E5` índigo (acadêmico) · `#EA580C` laranja (comunidade). |

### 8. Local / serviço de bairro (restaurante, pet, academia, salão, oficina)

| | |
|---|---|
| **Temperatura** | Quente, quase sempre. É negócio de gente, na rua. |
| **Face** | Display com caráter (condensada, arredondada ou script contida) + texto muito legível. |
| **Papel da cor** | Estrutural. Bloco de cor cheia funciona: é o que se lê da calçada e no story. |
| **Densidade** | Média. A informação que importa é telefone, endereço, horário e preço — tem que estar visível sem rolar. |
| **Raio / elevação** | Generoso e amigável, ou zero com cara de placa/letreiro. |
| **Assinaturas** | Cartão de horário de funcionamento · botão de WhatsApp como elemento de marca (não plugin genérico) · foto real do lugar, não de estoque. |
| **Evite** | Cara de SaaS · foto de banco de imagem de cachorro/prato/academia · fonte script ilegível no corpo. |
| **Cor de assinatura** | `#DC2626` vermelho apetite (comida) · `#0891B2` ciano (pet, limpeza) · `#CA8A04` mostarda (padaria, artesanal) · `#7C2D12` marrom (barbearia, oficina). |

## Bancos de face — o que usar em vez do padrão

**Nunca proponha Inter ou Space Grotesk como escolha "segura".** São a assinatura de "não escolhi".
Se Inter for tecnicamente a certa (raro, mas acontece), diga por que — e mude alguma coisa: tracking,
peso, uma serifada no display.

## Cor de assinatura — como escolher o tom, não a cor

1. **O hue vem do posicionamento** (tabela dos arquétipos), não do gosto.
2. **A saturação vem do público:** B2B sério pede saturação média (60–75%). Consumidor e criativo
   aguentam 85–100%.
3. **A luminosidade vem da base:** sobre fundo escuro a assinatura precisa de L ~55–65% pra brilhar;
   sobre fundo claro precisa de L ~40–50% pra não sumir.
4. **Teste o pior caso antes de fechar:** a cor como texto de 14px sobre a superfície de card.
   Se não passa 4.5:1, você não abandona a cor — você cria `--primary-on-light`.
5. **Um hue vizinho já é uma marca diferente.** `#10B981` (esmeralda) e `#22C55E` (verde-grama) leem
   como empresas distintas. Escolha o tom com a mesma seriedade com que escolheu a cor.

## Como escrever a proposta (formato de saída da Rodada 1)

> **B — "Terminal"**
> Assinatura: `#F97316` laranja-sinal. Base escura `#0A0A0A`, superfície `#171717`.
> Faces: **Geist** no display e no texto, **Geist Mono** em número, label e código.
> Cor funcional e escassa — laranja só em ação e estado. Densidade média-alta, raio 8px,
> borda no lugar de sombra.
> *Parece um terminal bem cuidado: nada decorativo, tudo no lugar, e o laranja só acende quando
> tem algo pra fazer.*
> **Assinatura memorável:** o cursor `▍` piscando depois do wordmark, e o número sempre monoespaçado.

Três dessas, lado a lado no preview. E a quarta saída: *"nenhuma dessas — o que te incomodou?"*
