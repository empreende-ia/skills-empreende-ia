# Template — anúncios

> Um pacote por **ângulo**, quatro ângulos por rodada (dor / prova / contrarian / demonstração).
> Não entregue quatro variações da mesma frase — isso não é teste, é desperdício.

```markdown
## Ângulo [1] — [dor / prova / contrarian / demonstração]
**Testa:** [a hipótese, em uma frase]
**Público:** [frio / morno / remarketing]

### Roteiro de vídeo (45s)
| Tempo | Fala | Na tela |
|---|---|---|
| 0–3s | [gancho] | [visual] |
| 3–10s | [problema renomeado] | |
| 10–25s | [mecanismo + demonstração] | [tela funcionando] |
| 25–40s | [prova com número] | [print] |
| 40–45s | [CTA único] | [botão] |

### Texto primário
**Curto (1 linha):**
**Médio (4 linhas):**
**Longo (8 linhas):**

<!-- A primeira linha precisa sobreviver ao "ver mais": 125 caracteres. -->

### Título (até 40 caracteres)
1. …
2. …
3. …

### Texto na imagem (máx. 6 palavras)
1. …
2. …
3. …

### CTA
1. …
2. …
```

## Checklist antes de subir

- [ ] A promessa do anúncio aparece **literalmente** na headline da página?
- [ ] O visual do anúncio reaparece na página?
- [ ] Nível de consciência bate com o da página?
- [ ] Legenda queimada no vídeo?
- [ ] Formato certo (9:16 story/reels · 4:5 ou 1:1 feed) — sem barra preta?
- [ ] Sem promessa de renda garantida, sem antes/depois de corpo, sem "você" acusatório?
- [ ] Todo número é real e sustentável se cobrarem? (`references/conformidade.md`)
