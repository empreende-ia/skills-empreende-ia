# QA — nenhuma peça sai com item CRÍTICO

> Serve pra dois usos: fechar peça própria, e **auditar copy alheia** (modo AUDITAR).
> Na auditoria, preencha o placar e ranqueie por impacto — headline e lead primeiro.

## Placar

| # | Item | Status |
|---|---|---|
| 1 | Headline promete **resultado** (não tópico) e tem número ou prazo | crítico / melhorar / ok |
| 2 | Os 3 primeiros parágrafos não falam de você | crítico / melhorar / ok |
| 3 | Existe prova **antes** do preço | crítico / melhorar / ok |
| 4 | O mecanismo tem **nome próprio** | crítico / melhorar / ok |

CRÍTICO quebra a conversão (ou é risco legal) · MELHORAR deixa dinheiro na mesa · OK ok

## Formato da auditoria

```markdown
## Placar: [N] CRÍTICO · [N] MELHORAR · [N] OK

### Os 3 consertos de maior impacto

**1. [item] — CRÍTICO**
Antes: "[trecho literal]"
Depois: "[reescrita]"
Por quê: [1–2 frases]

**2. …**
**3. …**

### O resto
[lista curta dos MELHORAR, uma linha cada]

### Recomendo
[reescrever a peça inteira / aplicar só os 3 / voltar pra oferta antes]
```

## Três perguntas finais

1. Se eu fosse o cético mais chato do público, qual "tá, mas…" ficou sem resposta?
2. Se essa peça converter, eu consigo **entregar** exatamente o que ela prometeu?
3. Eu compraria por esse preço? Se a resposta é não, o problema é a oferta — e copy não conserta.
